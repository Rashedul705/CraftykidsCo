PHASE 1: Core Fixes, Fraud Prevention & Real Business Reporting (Days 1 - 2)
================================================================================

[x] Section 1.1: Invoice QR Code & Order Tracking Alignment
    - Problem: Printed invoice QR code points to /track?orderId=... but /track only read ?order=...
    - Problem: Track page only inspected client localStorage on URL param load; scanning from phone showed "Order not found" because phone lacked desktop localStorage.
    - Solution:
      * Support `orderId`, `order`, `order_id`, and `id` in /track search params.
      * Auto-query `/api/orders/:id` and `/api/orders?phone=...` against MongoDB on load.
      * Add loading state and safe optional chaining for `timeline` array.
      * Sanitize website domain in `print-templates.ts`.
    - Status: [x] Completed

[x] Section 1.2: Database-Backed Block List & Checkout Fraud Interception
    - Problem: Admin 'block-list' is currently kept only in ephemeral React state; not saved to MongoDB.
    - Problem: Blocked numbers/IPs do not actually prevent fraudulent users from placing orders.
    - Solution:
      * Create `Blacklist` Mongoose model in backend & frontend (`phone`, `reason`, `riskLevel`, `createdAt`).
      * Add CRUD API endpoints `/api/blocklist` (GET, POST, DELETE).
      * Connect `SystemSettingsManager.tsx` (block-list tab) to real MongoDB API.
      * Add checkout validation interceptor in `/api/orders` to immediately block or flag blacklisted phone numbers.
    - Status: [x] Completed

[x] Section 1.3: Product Cost (COGS) & Real Profit Analytics in Reports Tab
    - Problem: Admin 'reports' tab displays static hardcoded numbers (e.g. ৳142,650).
    - Problem: Products lack `costPrice` (buying/manufacturing cost), making it impossible to see actual net profit.
    - Solution:
      * Add `costPrice` field to Product schema and admin Product modal/form.
      * Create `/api/reports/analytics` endpoint to dynamically calculate:
        - Gross Revenue
        - Total COGS (Cost of Goods Sold)
        - Net Profit (Revenue - COGS - Delivery Cost)
        - Order Status breakdown (Delivered, In-Transit, Returned)
        - Date-range filtering (Today, 7 days, 30 days, Custom)
      * Connect `SystemSettingsManager.tsx` (reports tab) to real MongoDB analytics.
    - Status: [x] Completed
