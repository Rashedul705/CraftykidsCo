1. PROJECT OVERVIEW & ARCHITECTURE
--------------------------------------------------------------------------------
Crafty Kids Co. is a specialized e-commerce platform designed for child-safe, 
non-toxic DIY plaster painting kits, natural wax crayons, and educational 
Montessori toys for toddlers and young kids in Bangladesh.

The repository is organized as a clean Monorepo:
├── frontend/             -> Next.js 16 (Turbopack, App Router, React 19, Tailwind CSS)
│   ├── src/app/          -> Pages & Routes (Storefront, Product, Shop, Cart, Checkout, Admin)
│   ├── src/components/   -> Reusable UI Components & Layouts (Header, Footer, ProductCard)
│   ├── src/lib/          -> Data store, sample-data, utilities, state handlers
│   └── public/images/    -> High-resolution product photos & branding assets
├── backend/              -> Express.js API Server
│   ├── server.js         -> REST API endpoints, static asset server & Glassmorphic Dashboard
│   └── package.json      -> Backend dependencies
├── .gitignore            -> Strict credential & environment security
└── README.md             -> Monorepo documentation & setup instructions
